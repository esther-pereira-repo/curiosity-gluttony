r## Estrutura de pasta — OBRIGATÓRIO 
Cada página DEVE ser salva na pasta correta: 
- wiki/people/ → qualquer pessoa real (artista, autor, filósofo, historiador)
- wiki/works/ → obras específicas (livro, quadro, série, filme, poema) 
- wiki/concepts/ → ideias abstratas (feminismo, sublime, performance, identidade)
- wiki/periods/ → épocas e movimentos (Renascimento, Modernismo, Anos 70) 
- wiki/sources/ → resumo da fonte original ingerida 
## Idioma
- Títulos em português 
- Aliases em outros idiomas apontam para a página principal 
## Regras de links 
1. Toda página de obra linka para pessoa e período 
2. Toda página de pessoa linka para suas obras e período 
3. Sempre adicione backlinks entre páginas relacionadas 
4. Nunca crie duas páginas para o mesmo conceito
